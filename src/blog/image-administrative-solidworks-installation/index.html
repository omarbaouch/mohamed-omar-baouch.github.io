1. Ce qu'est (vraiment) une image administrative1. What an administrative image really is

Quand vous installez SOLIDWORKS « normalement » sur un poste, le programme d'installation télécharge ou lit plusieurs dizaines de Go, puis pose les composants en vous posant une série de questions : produits, dossier, numéro de série, options. Refaites cela sur quinze postes et vous obtenez quinze installations légèrement différentes — et deux jours perdus.When you install SOLIDWORKS "the normal way" on a workstation, the installer downloads or reads several tens of GB, then lays down the components while asking a series of questions: products, folder, serial number, options. Repeat that on fifteen workstations and you get fifteen slightly different installations — and two lost days.

Une image administrative inverse la logique : l'administrateur répond une seule fois aux questions, et le résultat est stocké sur un partage réseau avec tous les fichiers nécessaires. Chaque poste n'a plus qu'à lancer l'installation depuis ce partage, et obtient exactement la même configuration que les autres.An administrative image reverses the logic: the administrator answers the questions once, and the result is stored on a network share together with every required file. Each workstation then only has to start the installation from that share, and ends up with exactly the same configuration as the others.

Le vrai bénéfice n'est pas le temps gagné à l'installation. C'est la disparition d'une catégorie de pannes : « chez moi ça marche, chez lui non ». Quand tous les postes viennent de la même image, un problème reproductible sur un poste l'est sur tous — et se corrige une fois.The real benefit is not the time saved at install. It is the disappearance of an entire category of failures: "it works for me, not for him". When every workstation comes from the same image, a problem reproducible on one machine is reproducible on all — and gets fixed once.

2. Préparer le terrain avant de toucher au gestionnaire d'installation2. Preparing the ground before touching the Installation Manager

La moitié des images administratives qui échouent échouent à cause de ce qui entoure l'image, pas de l'image elle-même. Cinq points à régler avant de lancer la création :Half of the administrative images that fail, fail because of what surrounds the image, not the image itself. Five points to settle before starting the creation:

  • Un partage réseau dédié, en chemin UNC (\\serveur\SW_Images), jamais un lecteur réseau mappé : un poste qui s'installe via un script de démarrage ne voit pas les lecteurs mappés d'un utilisateur.A dedicated network share, as a UNC path (\\server\SW_Images), never a mapped network drive: a workstation installing through a startup script does not see a user's mapped drives.
  • Des droits maîtrisés : écriture pour les administrateurs seulement, lecture pour les comptes ordinateurs (ou le groupe « Ordinateurs du domaine ») et pour les utilisateurs qui installent. C'est l'oubli numéro un des déploiements par GPO.Controlled rights: write access for administrators only, read access for computer accounts (or the "Domain Computers" group) and for the users who install. It is the number-one oversight in GPO deployments.
  • De l'espace : une quinzaine de Go pour une image SOLIDWORKS 2020 (davantage depuis), et le double si vous gardez la version précédente le temps de la transition. Un volume dédié de 100 Go est un bon ordre de grandeur.Space: about 15 GB for a SOLIDWORKS 2020 image (more since), and twice that if you keep the previous version during the transition. A dedicated 100 GB volume is a good order of magnitude.
  • Les numéros de série et le type de licence sous la main : autonome (un numéro par poste) ou réseau (un serveur SNL). Ce choix détermine la suite — voir la section 5.Serial numbers and license type at hand: standalone (one number per workstation) or network (an SNL server). This choice drives what follows — see section 5.
  • Un poste d'essai propre, de préférence une machine virtuelle, pour valider l'image avant de la montrer au parc. Un snapshot, un essai, un retour arrière : une heure qui économise une journée.A clean test machine, preferably a virtual machine, to validate the image before exposing it to the fleet. Snapshot, trial, roll-back: an hour that saves a day.

Pensez aussi à nommer l'image avec la version (SW2025_SP3, par exemple) et à tenir un petit fichier texte à la racine : date de création, numéro de Service Pack, qui l'a faite, ce qui a été réglé. Dans deux ans, ce fichier vaudra de l'or.Also name the image with its version (SW2025_SP3, for example) and keep a small text file at the root: creation date, Service Pack number, who built it, what was configured. In two years, that file will be worth gold.

Le matériel des postes cibles compte autant que l'image : voir le guide de configuration matérielle SOLIDWORKS pour valider qu'un poste est prêt à recevoir la version visée.The target workstations' hardware matters as much as the image: see the SOLIDWORKS hardware configuration guide to check that a workstation is ready for the target version.

3. Créer l'image pas à pas3. Creating the image step by step

Le point d'entrée est le même que pour une installation classique : le programme d'installation SOLIDWORKS, téléchargé depuis votre espace client ou lu depuis un support. Les libellés exacts évoluent légèrement d'une version à l'autre, mais la séquence reste celle-ci.The entry point is the same as for a classic installation: the SOLIDWORKS installer, downloaded from your customer portal or read from media. Exact labels change slightly from one version to the next, but the sequence stays the same.

Les captures d'écran de cet article proviennent d'un guide Visiativ réalisé sous SOLIDWORKS 2020 : d'une version à l'autre, ces écrans ont très peu changé. Les numéros de série et identifiants y ont été masqués.The screenshots in this article come from a Visiativ guide made with SOLIDWORKS 2020 (French interface): these screens have changed very little from one version to the next. Serial numbers and credentials have been masked.

  1. Lancez le programme d'installation avec un compte administrateur et choisissez le type d'installation « Image administrative » (créer une image pour déployer sur plusieurs ordinateurs), et non « Installation individuelle ».Start the installer with an administrator account and choose the "Administrative image" installation type (create an image for deployment to several computers), not "Individual installation".
  2. Choisissez le mode de création : « créer une nouvelle image avec les paramètres par défaut », ou « créer une nouvelle image à partir des paramètres et fichiers d'une image existante » — utile à chaque nouvelle version pour reprendre vos réglages.Choose the creation mode: "create a new image using default settings", or "create a new image using settings and files from an existing image" — useful with each new version to carry your settings over.
  3. Saisissez les numéros de série. Ils déterminent les produits proposés ensuite. Avec une licence réseau, vous n'aurez pas à les distribuer aux postes : seule l'adresse du serveur sera embarquée.Enter the serial numbers. They determine the products offered next. With a network license you will not need to hand them to workstations: only the server address will be embedded.
  4. Indiquez l'emplacement de l'image : un dossier propre à la version. L'emplacement proposé par défaut est C:\SOLIDWORKS Admin ; il est recommandé de créer l'image sur un disque local (plus rapide et plus stable), puis de copier le dossier terminé vers le partage UNC préparé à l'étape 2.Specify the image location: a folder specific to the version. The default location offered is C:\SOLIDWORKS Admin; it is recommended to build the image on a local disk (faster and more stable), then copy the finished folder to the UNC share prepared in step 2.
  5. Cochez les produits à inclure : SOLIDWORKS, Simulation, Visualize, Electrical, PDM, Toolbox… N'embarquez que ce que vous déploierez réellement : chaque produit alourdit l'image et allonge chaque installation.Tick the products to include: SOLIDWORKS, Simulation, Visualize, Electrical, PDM, Toolbox… Only embed what you will really deploy: every product makes the image heavier and every installation longer.
  6. Lancez le téléchargement. L'outil rapatrie tous les fichiers dans le partage : c'est l'étape longue, à lancer en fin de journée.Start the download. The tool pulls every file into the share: it is the long step, so start it at the end of the day.

For anything that commits the deployment, the official installation guide of the target version is authoritative: this article gives the method and the traps, not reference documentation.

4. Configurer l'image : l'éditeur d'options4. Configuring the image: the options editor

Créer l'image ne suffit pas. Sa valeur vient de ce que vous y préréglez : c'est là que les quinze installations deviennent une. Les réglages se font dans l'éditeur d'options de l'image administrative, que vous ouvrez avec le bouton « Personnaliser l'image » du gestionnaire d'installation, ou en lançant sldAdminOptionEditor.exe depuis le dossier racine de l'image. Les réglages « globaux » s'appliquent à tous les postes, sauf s'ils sont redéfinis pour un groupe ou une machine précise. Voici les familles de réglages qui comptent, par ordre d'impact.Creating the image is not enough. Its value comes from what you preset inside it: that is where fifteen installations become one. Settings are made in the administrative image options editor, which you open with the "Customize Image" button of the Installation Manager, or by running sldAdminOptionEditor.exe from the image root folder. "Global" settings apply to every workstation unless overridden for a specific group or machine. These are the families of settings that matter, in order of impact.

L'éditeur propose trois niveaux : les paramètres globaux, valables pour tous, puis des groupes de machines et des ordinateurs isolés — désignés par leur nom, leur adresse IP ou une plage d'adresses. Un service qui n'a pas besoin de Simulation, ou une machine qui reçoit une licence différente, hérite des réglages globaux, auxquels on ajoute ou retire des éléments. Les options propres à un niveau s'affichent en noir (ajoutées) ou en rouge (retirées par rapport au réglage global).The editor offers three levels: global settings, valid for everyone, then machine groups and individual computers — identified by name, IP address or address range. A department that does not need Simulation, or a machine receiving a different license, inherits the global settings, to which you add or remove items. Options specific to a level appear in black (added) or red (removed compared with the global setting).

Autres réglages utiles de la rubrique « Options d'installation du client » : mettre à niveau la version majeure existante ou en créer une nouvelle en parallèle, utiliser les paramètres actuels du poste ou un fichier de paramètres exporté, et activer ou non automatiquement la licence en fin d'installation. Dans « Options d'administration », on peut aussi exécuter l'installation sous un autre compte pour les postes dont l'utilisateur n'a pas de droits d'administrateur.Other useful settings under "Client installation options": upgrade the existing major version or create a new one alongside it, use the workstation's current settings or an exported settings file, and activate or not the license automatically at the end of installation. Under "Administration options" you can also run the installation under another account for workstations whose user has no administrator rights.

Le fichier de paramètres : le geste le plus rentableThe settings file: the most profitable move

Réglez un poste de référence aux standards du bureau d'études (unités, options de document, emplacements, couleurs, raccourcis), puis exportez ses paramètres avec l'assistant de copie de paramètres dans un fichier .sldreg. Importé dans l'image, il s'applique à chaque nouvelle installation. C'est ce qui évite le fameux « ton SOLIDWORKS n'est pas réglé comme le mien ».Set one reference workstation to the design office standards (units, document options, locations, colours, shortcuts), then export its settings with the Copy Settings Wizard into a .sldreg file. Imported into the image, it applies to every new installation. It is what ends the famous "your SOLIDWORKS isn't set up like mine".

Même logique pour la Toolbox : une seule bibliothèque, à un emplacement partagé, écrite par une seule personne. C'est exactement la correction durable décrite dans l'article sur les 10 erreurs SOLIDWORKS les plus fréquentes — l'image administrative est l'endroit où l'on pose ce réglage une bonne fois.Same logic for the Toolbox: a single library, at a shared location, written by one person. It is exactly the durable fix described in the article on the 10 most common SOLIDWORKS errors — the administrative image is where you set it once and for all.

5. Licences : autonome ou réseau (SNL)5. Licensing: standalone or network (SNL)

L'image n'invente pas votre modèle de licence, elle le matérialise. Deux cas :The image does not invent your license model, it materialises it. Two cases:

  • Licences autonomes : un numéro de série par poste. Pratique pour un petit parc ou des postes nomades ; pénible dès que le parc grossit, car chaque installation ou réactivation passe par un numéro.Standalone licenses: one serial number per workstation. Convenient for a small fleet or mobile workstations; painful once the fleet grows, because every installation or reactivation goes through a number.
  • Licences réseau (SolidNetWork License, SNL) : un gestionnaire de licences installé une fois sur un serveur, et des postes qui « empruntent » une licence à l'ouverture. L'adresse du serveur est embarquée dans l'image sous la forme port@serveur, et le poste ne demande rien à l'utilisateur.Network licenses (SolidNetWork License, SNL): a license manager installed once on a server, and workstations that "borrow" a license on launch. The server address is embedded in the image as port@server, and the workstation asks the user nothing.

Quelques points de vigilance sur le serveur SNL : une machine stable (pas le portable d'un technicien), un nom ou une adresse fixes, les ports du pare-feu ouverts (le port par défaut du gestionnaire est 25734, avec un second port pour le démon de licence) et une sauvegarde du fichier de licence. Un serveur de licences en panne, c'est tout le bureau d'études à l'arrêt.A few watch points on the SNL server: a stable machine (not a technician's laptop), a fixed name or address, open firewall ports (the manager's default port is 25734, with a second port for the license daemon) and a backup of the license file. A license server down means the whole design office at a standstill.

6. Déployer sur les postes6. Deploying to the workstations

L'éditeur d'options contient lui-même les outils de déploiement, dans deux onglets dédiés — « Déployer manuellement » et « Déployer automatiquement ». Dans tous les cas, le compte qui installe doit avoir au minimum les droits de lecture sur le dossier de l'image ; et si vous voulez récupérer les journaux d'installation de chaque poste et leur statut, le compte doit pouvoir écrire dans le sous-dossier 64bit\logs de l'image.The options editor itself contains the deployment tools, in two dedicated tabs — "Deploy manually" and "Deploy automatically". In every case, the installing account needs at least read rights on the image folder; and if you want each workstation's installation logs and status back, the account must be able to write to the image's 64bit\logs subfolder.

A. Manuel : un lien vers StartSWInstall.htaA. Manual: a link to StartSWInstall.hta

À la racine de l'image se trouve le fichier StartSWInstall.hta. L'onglet « Déployer manuellement » permet d'envoyer par e-mail un lien vers ce fichier : l'utilisateur clique, et l'installation de l'image démarre sur son poste. On peut aussi parcourir le dossier de l'image et lancer le fichier à la main. Suffisant pour une petite équipe, et idéal pour valider l'image sur le poste d'essai.At the image root sits the StartSWInstall.hta file. The "Deploy manually" tab lets you send an e-mail with a link to that file: the user clicks, and the image installation starts on their workstation. You can also browse to the image folder and launch the file by hand. Enough for a small team, and ideal for validating the image on the test machine.

B. Automatique : une installation silencieuse poussée depuis l'éditeurB. Automatic: a silent installation pushed from the editor

L'onglet « Déployer automatiquement » pousse l'installation de façon silencieuse, sans interaction de l'utilisateur, sur les postes cochés : maintenant ou plus tard, installation ou mise à niveau, désinstallation, redémarrage automatique en option. Il exige un compte disposant des droits d'administrateur complets sur les machines visées, à renseigner dans l'écran (domaine, nom d'utilisateur, mot de passe). Un bouton de test permet de vérifier avant de lancer.The "Deploy automatically" tab pushes the installation silently, with no user interaction, to the ticked workstations: now or later, install or upgrade, uninstall, optional automatic restart. It requires an account with full administrator rights on the target machines, entered on the screen (domain, user name, password). A test button lets you check before launching.

La syntaxe exacte change d'une version à l'autre : copiez-la depuis la page « Installation depuis l'image administrative en ligne de commande » du guide de votre version, plutôt que depuis un article — celui-ci compris. Un script de démarrage s'exécute avec le compte de l'ordinateur : d'où l'importance, vue en section 2, du chemin UNC et des droits de lecture accordés aux comptes ordinateurs.For a fleet already driven by SCCM, Intune or startup scripts, the SOLIDWORKS installation guide describes command-line installation from the image. The exact syntax changes from one version to the next: copy it from the "Installing from the Administrative Image Using the Command Line" page of the guide for your version, rather than from an article — this one included. A startup script runs under the computer account: hence the importance, seen in section 2, of the UNC path and of read rights granted to computer accounts.

Étalez les installations. Cinquante postes qui lisent une image de plusieurs dizaines de Go en même temps sur un même partage saturent le réseau et le serveur : tout le monde attend, certaines installations échouent par délai dépassé. Déployez par vagues (dix postes à la fois) ou, sur plusieurs sites, répliquez l'image sur un partage local à chaque site.Stagger the installations. Fifty workstations reading a multi-GB image at the same time from one share saturate the network and the server: everyone waits, some installations fail on timeout. Deploy in waves (ten workstations at a time) or, across several sites, replicate the image to a local share at each site.

Si vous déployez aussi le client PDM, choisissez dans l'éditeur le produit (Standard ou Professional) et le type de client (Editor, Contributor ou Viewer). La vue locale du coffre, elle, se configure ensuite à la main sur chaque poste. C'est un chapitre à part entière du guide complet SOLIDWORKS PDM.If you also deploy the PDM client, pick in the editor the product (Standard or Professional) and the client type (Editor, Contributor or Viewer). The local vault view is then configured by hand on each workstation. It is a full chapter of the complete SOLIDWORKS PDM guide.

7. Service Packs et nouvelles versions : garder l'image à jour7. Service Packs and new versions: keeping the image current

Une image administrative est un actif vivant. Deux situations, deux règles :An administrative image is a living asset. Two situations, two rules:

  • Un nouveau Service Pack (SP) : on met à jour l'image existante depuis le gestionnaire d'installation, on la valide sur le poste d'essai, puis on propage aux postes. On ne recrée pas une image par SP.A new Service Pack (SP): you update the existing image from the Installation Manager, validate it on the test machine, then propagate it to workstations. You do not create a new image for each SP.
  • Une nouvelle version majeure : on crée une nouvelle image, dans un dossier distinct, et on garde l'ancienne tant que des projets en cours en dépendent. SOLIDWORKS ne rouvre pas en arrière un fichier enregistré dans une version plus récente : la montée de version est une décision de bureau d'études, pas seulement d'informatique.A new major version: you create a new image, in a separate folder, and keep the old one as long as ongoing projects depend on it. SOLIDWORKS does not reopen backward a file saved in a newer version: the version move is a design-office decision, not just an IT one.

Une astuce documentée par Visiativ : à chaque lancement, SOLIDWORKS vérifie le contenu du dossier partagé qui contient l'image. Si vous donnez à la nouvelle image le même nom de partage que l'ancienne (et supprimez le partage de l'ancienne), les postes voient une version plus récente et se mettent à niveau automatiquement au démarrage de SOLIDWORKS. Pratique, mais cela retire la maîtrise du calendrier : à n'utiliser qu'une fois la version validée par le groupe pilote.A tip documented by Visiativ: at every launch, SOLIDWORKS checks the contents of the shared folder holding the image. If you give the new image the same share name as the old one (and remove the old share), workstations see a newer version and upgrade automatically when SOLIDWORKS starts. Convenient, but it takes away control of the timing: use it only once the version has been validated by the pilot group.

Dans les deux cas, validez avant de généraliser : un groupe pilote de deux ou trois utilisateurs, pendant une à deux semaines, sur des assemblages réels. Si vous utilisez un coffre PDM, vérifiez aussi la compatibilité de la version cible avec votre serveur PDM avant de toucher au parc — c'est le sujet traité dans la migration de données vers SOLIDWORKS PDM.In both cases, validate before generalising: a pilot group of two or three users, for one to two weeks, on real assemblies. If you use a PDM vault, also check the target version's compatibility with your PDM server before touching the fleet — the subject covered in migrating data to SOLIDWORKS PDM.

10. FAQ

Qu'est-ce qu'une image administrative SOLIDWORKS ?What is a SOLIDWORKS administrative image?

C'est une copie complète du programme d'installation, déposée sur un partage réseau et préconfigurée par l'administrateur (produits, licence, emplacements, paramètres). Chaque poste s'installe ensuite depuis ce partage, sans retélécharger les fichiers et sans que l'utilisateur ait de choix à faire.It is a complete copy of the installer, placed on a network share and preconfigured by the administrator (products, license, locations, settings). Each workstation then installs from that share, without re-downloading the files and without the user having any choices to make.

Quelle place faut-il prévoir pour l'image ?How much space should I plan for the image?

L'image contient l'intégralité des sources : environ 15 Go pour SOLIDWORKS 2020 selon le guide Visiativ, davantage avec les versions récentes et les produits cochés (le gestionnaire affiche la taille estimée avant création). Comptez large : une image par version majeure et par Service Pack conservé. Un volume dédié de 100 Go évite de se reposer la question.The image holds the complete installation sources: about 15 GB for SOLIDWORKS 2020 according to the Visiativ guide, more with recent versions and ticked products (the installer shows the estimated size before creation). Plan generously: one image per major version and per Service Pack kept. A dedicated 100 GB volume avoids asking the question again.

Peut-on installer depuis l'image sans droits administrateur ?Can I install from the image without administrator rights?

Non : l'installation exige des droits administrateur local sur le poste. L'image ne les contourne pas, elle uniformise l'installation. Pour un parc, on passe donc par un script de démarrage, un outil de déploiement (SCCM, Intune) ou une intervention du support.No: installation requires local administrator rights on the workstation. The image does not bypass them, it standardises the installation. For a fleet, you therefore use a startup script, a deployment tool (SCCM, Intune) or a support intervention.

Faut-il une image administrative par version de SOLIDWORKS ?Do I need one administrative image per SOLIDWORKS version?

Oui, une par version majeure (2024, 2025, 2026…), dans des dossiers distincts et nommés explicitement. Les Service Packs, eux, se mettent à jour dans l'image existante : ne créez pas une nouvelle image à chaque SP.Yes, one per major version (2024, 2025, 2026…), in separate, explicitly named folders. Service Packs, however, are updated inside the existing image: do not create a new image for every SP.

Image administrative et licences réseau : quel lien ?Administrative image and network licenses: what is the link?

L'image peut embarquer l'adresse du serveur de licences (SolidNetWork License) pour que chaque poste le trouve seul, sans saisie. Le serveur de licences, lui, s'installe à part, une fois, sur une machine dédiée ou stable.The image can embed the license server address (SolidNetWork License) so that each workstation finds it on its own, with no typing. The license server itself is installed separately, once, on a dedicated or stable machine.

Peut-on inclure le client PDM dans le déploiement ?Can the PDM client be included in the deployment?

Oui : le client SOLIDWORKS PDM figure dans la liste des logiciels à installer, et l'éditeur d'options permet de choisir le produit (Standard ou Professional) et le type de client (Editor, Contributor, Viewer). Attention : la vue locale du coffre se configure ensuite manuellement sur chaque poste, ou par un script que vous préparez à part. C'est le moyen le plus fiable d'aligner la version de client sur celle du serveur.Yes: the SOLIDWORKS PDM client is in the list of software to install, and the options editor lets you pick the product (Standard or Professional) and client type (Editor, Contributor, Viewer). Note that the local vault view is then configured manually on each workstation, or by a script you prepare separately. It is the most reliable way to align the client version with the server's.
